# 医疗广告高风险措辞审查

对医疗广告脚本中的高风险承诺进行规则版本化审查和人工裁定。

## 参与方与事实

主要参与方包括内容安全团队、医学顾问、广告审核人员、品牌运营人员。领域资料记录以下事实：

- 广告中出现根治、断根、停药等绝对化表述
- 仿冒专业人士的内容会让患者误以为得到正规建议
- 平台需要把高风险健康内容的审核前移

## 业务边界

- 词条版本
- 上下文例外
- 风险等级
- 人工复核
- 规则生效日

当前资料按以下边界组织：

- 规则库
- 脚本分段
- 风险命中
- 人工裁定
- 批量重审

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/policy_context.py` 负责读取和校验资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

命令只读取仓库内文件，不需要连接外部业务系统。
